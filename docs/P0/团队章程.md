## 三、AI工具链选型评估表

|工具类型|候选工具|选择/不选择|理由|
|-|-|-|-|
|AI编程助手|GitHub Copilot|✅ 选择|功能强大，支持多语言，团队熟悉，学生免费|
|AI编程助手|Cursor|❌ 不选择|界面新颖但团队使用习惯不统一|
|AI对话工具|ChatGPT|✅ 选择|文档生成、需求分析能力强，团队常用|
|AI对话工具|文心一言|❌ 不选择|生成质量不稳定，功能较弱|
|AI代码审查|CodeRabbit|✅ 选择|自动化审查，集成GitHub，适合CI流程|
|AI代码审查|AI Code Reviewer|❌ 不选择|功能简单，缺乏深度分析|
|AI测试工具|TestPilot|✅ 选择|自动生成单元测试，兼容Jest/Pytest|
|AI测试工具|Diffblue Cover|❌ 不选择|成本高，Java支持为主，不适合本项目|
