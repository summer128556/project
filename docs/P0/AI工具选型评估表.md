# AI工具选型评估表

**团队名称**：哪一队
**评估日期**：2026年4月9日  
**评估参与人**：韩序、罗昕雅、陈朵朵、王雨婷

## 一、AI编程助手

|评估维度|GitHub Copilot|Cursor|
|-|-|-|
|功能完整性|支持代码补全、函数生成、注释生成、多文件编辑|类似Copilot，强调对话式编程|
|易用性|插件丰富，支持VS Code、JetBrains等主流IDE|独立编辑器，需切换习惯|
|成本|**学生免费** / 团队版按年收费|免费版功能受限，Pro版$20/月|
|团队熟悉度|3人有过使用经验|1人试用过|
|语言支持|Python, JavaScript, TypeScript, Java, Go等|相近|
|选择/不选择|✅ **选择**|❌ 不选择|

### 选择 GitHub Copilot 的理由：

* 团队熟悉度高，学习成本低
* 学生可免费使用，无额外成本
* 与主流IDE无缝集成，不影响现有开发流程
* 代码生成质量稳定，社区活跃

### 不选择 Cursor 的理由：

* 需要切换到独立编辑器，改变开发习惯
* 免费版功能受限，团队需要统一工具链
* 团队仅1人有使用经验，学习成本较高

## 二、AI对话工具

|评估维度|ChatGPT|文心一言|
|-|-|-|
|功能完整性|文档生成、需求分析、代码解释、测试用例设计|类似功能，中文理解较好|
|易用性|Web/App，界面简洁，响应快|Web/App，界面友好|
|成本|**免费版可用** / Plus $20/月|**免费**|
|团队熟悉度|全员日常使用|1人偶尔使用|
|生成质量|结构化强，逻辑清晰|部分回答较泛，深度不足|
|选择/不选择|✅ **选择**|❌ 不选择|

### 选择 ChatGPT 的理由：

* 全员熟悉，无需额外培训
* 生成文档结构清晰，适合需求分析和文档撰写
* 免费版已满足项目需求
* 支持长对话上下文，便于迭代讨论

### 不选择 文心一言 的理由：

* 生成内容的深度和结构化程度不及ChatGPT
* 团队整体熟悉度低
* 在代码生成和技术文档方面表现较弱

\---

## 三、AI代码审查工具

|评估维度|CodeRabbit|AI Code Reviewer|
|-|-|-|
|功能完整性|自动化PR审查、代码质量建议、安全检测|基础代码风格检查、简单注释建议|
|易用性|GitHub App，一键安装，自动评论PR|需手动配置API|
|成本|**开源项目免费** / 团队版付费|免费（社区版）|
|集成能力|深度集成GitHub Actions|需自定义CI流程|
|审查深度|逻辑漏洞、性能问题、安全风险|以风格检查为主|
|选择/不选择|✅ **选择**|❌ 不选择|

### 选择 CodeRabbit 的理由：

* 深度集成GitHub，与CI流程无缝配合
* 审查维度全面，不仅限于风格检查
* 自动化程度高，减少人工审查负担
* 开源项目可免费使用

### 不选择 AI Code Reviewer 的理由：

* 功能过于简单，主要是风格检查
* 需要手动配置，集成成本高
* 缺乏深度的逻辑和安全分析能力

## 四、AI测试工具

|评估维度|TestPilot|Diffblue Cover|
|-|-|-|
|功能完整性|自动生成单元测试，兼容Jest/Pytest|自动生成Java单元测试|
|易用性|VS Code插件，一键生成|IDE插件，需配置|
|成本|**免费**|付费（企业版）|
|语言支持|JavaScript/TypeScript, Python|仅Java|
|项目适配性|✅ 匹配本项目技术栈|❌ 不匹配|
|选择/不选择|✅ **选择**|❌ 不选择|

### 选择 TestPilot 的理由：

* 完全匹配项目技术栈（Python + JavaScript）
* 免费使用，无额外成本
* 与VS Code集成，开发体验流畅
* 自动生成测试用例，提升测试覆盖率

### 不选择 Diffblue Cover 的理由：

* 仅支持Java，与项目技术栈不匹配
* 企业版收费，超出项目预算
* 团队无Java开发经验

|工具类型|选定工具|主要理由|
|-|-|-|
|AI编程助手|GitHub Copilot|免费、熟悉、集成好|

|AI代码审查|CodeRabbit|深度集成、自动化强|
