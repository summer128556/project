\## 项目简介

本项目旨在实践AI辅助软件开发流程，探索人机协作的最佳实践。通过角色轮换和AI工具链的规范使用，提升团队协作效率与工程能力。



\## 技术栈

\- 后端：Java 17 + Spring Boot 3.x + Maven

\- 前端：Vue 3 + Vite

\- 数据库：MySQL / H2（开发环境）

\- CI/CD：GitHub Actions

\- 版本控制：Git
